# 📱 AppliQ - Smart Job Application Tracker Mobile App

**AppliQ** adalah aplikasi mobile pelacak lamaran kerja (job application tracker) modern yang dirancang untuk membantu para pencari kerja mengelola, memantau, dan menganalisis seluruh proses lamaran kerja secara rapi, terstruktur, dan real-time dengan backend **Supabase**.

---

## 🌟 Fitur Utama (Core Features)

- 📋 **Job Tracker & Status Pipeline**: Melacak status lamaran mulai dari *Applied*, *Interview*, *Offering*, *Accepted*, hingga *Rejected* / *No Response*.
- 📊 **Interactive Analytics Dashboard**: Statistik total lamaran, persentase konversi tiap portal kerja (LinkedIn, JobStreet, Glints, dll.), dan distribusi model kerja (*On-site*, *Hybrid*, *WFH*).
- ⏱️ **Smart Dynamic Feedback**: Notifikasi dan indikator durasi lamaran (e.g. *Dikirim hari ini*, *Dikirim X hari lalu*, *Follow up needed*).
- 📅 **Interview & Stage Logs**: Catatan jadwal wawancara, nama interviewer, dan feedback hasil tes.
- 🔒 **Secure Multi-User (Supabase RLS)**: Keamanan data terisolasi per pengguna dengan Supabase Authentication & Row Level Security.
